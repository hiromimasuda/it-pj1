# 初期ターゲット・利用場面・適合判定

## 第一ターゲット候補

従業員10〜150名程度の中小企業・ベンチャー企業で、自身も実務を持つ以下の人。

- 経営者
- 事業責任者
- 部門責任者
- 少額の業務改善を判断できるマネージャー

想定職種：

- マーケティング
- 採用・人事
- 営業企画
- 管理部門
- 事業企画

## 比較ターゲット

- PC業務を多く持つ個人事業主
- 時間削減が売上へ影響する
- 自分で導入判断できる
- 実業務を見せられる

## 適合条件

- 毎週または毎月繰り返す
- 1回30分以上
- 14日以内に2回以上実行
- 実作業を見せられる
- 本人が変更を試せる
- Before／Afterを記録できる
- 匿名化できる
- 少額でも支払う意思がある

## 不適合条件

- AIを一般的に学びたいだけ
- 改善業務がない
- 実行時間がない
- 変更権限がない
- 全部代行してほしい
- 高度な独自開発が前提
- 心身不調、人間関係、組織対立が中心
- 法務・医療・税務等の専門判断
- 匿名化できない
- 14日以内に業務が発生しない

## 代表ユースケース

### UC-01 承認依頼文

測定：作成時間、修正回数、差し戻し、負担感。

### UC-02 週次・月次報告

測定：作成時間、抜け漏れ、修正回数、再利用回数。

### UC-03 企画書初稿

測定：初稿時間、レビュー修正、不足論点、負担感。

## 最初の価値体験

> 顧客が実業務を、改善後の手順とテンプレートで一度完了し、従来より短時間または少ない修正で許容品質へ到達した瞬間。
