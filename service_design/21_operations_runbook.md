# 21 運用ランブック(1案件の実行手順)

- 状態:仮案。1案件をこの順に実行すれば回る状態にした手順書。詳細定義は `08_delivery_operation.md`、時間記録は都度 `19` へ。
- 前提ツール(既存のみ):Google カレンダー+Meet(日程・ヒアリング)/Google Docs(成果物)/メール・LINE・Slack等の相手が使う連絡手段/銀行振込(支払い・`27`仮案)。

## 案件フォルダの作り方(ローカル・リポジトリ外)

```text
案件_[番号]/            ← 実名・生データはこの中だけ。リポジトリに置かない
├─ 00_連絡ログ.md       ← 日付・要点のみ
├─ 01_事前質問回答.md
├─ 02_ヒアリングメモ.md  ← 終了後48時間以内に匿名化版を作る
├─ 03_改善シート.md      ← `16`を複製
├─ 04_実行キット/       ← `23`/`24`を複製して調整
├─ 05_before_after.md   ← `17`を複製
├─ 06_時間記録.md       ← `19`を複製
└─ 99_削除記録.md       ← 削除対象・予定日・実施日
```

## フェーズ1:獲得(Day -7〜0)

1. 候補者リスト(`26`)から次の1名を選ぶ → 提案文(`18`の1〜3)を個別調整して送付。**送付日を`26`に記録**
2. 返信あり → 適合確認15分:①業務名・頻度・1回の時間 ②直近14日で2回以上実行するか(月次系なら開始時期をずらす提案)③画面共有・匿名化の可否 ④本人が変更を試せるか
3. 適合 → 一枚説明(`13`)+情報管理方針(`09`前半)を送付
4. 前向き返信 → 日程2枠提示+支払い案内(`18`の4)。**入金確認をもって日程確定**
5. 入金確認 → 事前質問(`14`)送付+申込み確認事項(`27`)への同意を取得
6. 未返信は5日後にリマインド1回(`18`の5)のみ。以降追わず`26`に結果記録

## フェーズ2:設計(Day 1〜4)

7. 事前質問回答を確認 → 観察ポイント2〜3個をメモ(`15`事前準備)
8. **Day 1:ヒアリング60分**(`15`の台本どおり)。必須アウトプット:Day 0基準値/最初に変える工程の一文/初回テスト日+二回目実行日の確定
   - ⑤組織問題が主因 → その場で中止判定 → `18`の6(返金案内)→ 工程終了、`26`に記録
9. 48時間以内:ヒアリングメモの匿名化 → 改善シート(`16`)前半を記入 → 改善案を順序どおり比較(廃止→…→AI)
10. 実行キット作成:雛形(`23`/`24`)を複製し顧客の実業務に合わせて調整。**90分上限・150分到達で点数を削って先へ進む**。AI初心者ならプロンプト1本に絞る
11. 改善シート完成版+キットを初回テスト前日までに送付(「当日は◯◯さんに操作していただきます」と予告)

## フェーズ3:実行(Day 5〜14)

12. **初回テスト30分**:顧客本人が操作(Hiromiは口頭のみ。手を出したら`17`に記録)。所要時間を計測 → `17`に記入。つまずいた箇所はその場でキット修正
13. 終了時に確認:「二回目は【日付】に、お一人でやってみてください。質問はDay 7にまとめて聞きます」
14. **Day 7(15分)**:二回目の自力実行を確認(未実行なら理由を型の問題/対象外問題で切り分け)。数字を`17`へ。軽微修正はここで1回だけ
15. **Day 14(15分)**:Before/After確定 → 本人の判断(続ける/修正/やめる)を本人の言葉で記録 → 紹介・次業務の打診(`18`の7)

## フェーズ4:終了(Day 14〜21)

16. 成果物最終版を送付 → 事例化の許可打診 → 許可があれば匿名事例1段落を作成し本人確認
17. `19`の時間記録を締めて検証C判定 → `26`の検証トラッカーに転記
18. 生データの削除予定日(終了後30日以内)を`99_削除記録.md`に設定。実施したら日付記録
19. ふりかえり10分:次案件へ再利用するもの/やめることを`19`末尾に記録

## 例外処理

- 顧客都合のドタキャン → 1回目は再調整、2回目は「状況が変わったら再開しましょう」で凍結(追わない)
- 修正要望2回目以降 → 「Day 14の評価に含めて一緒に判断しましょう」で受け止め、その場で作業しない
- スコープ拡大要望(別業務も見て等)→ 「今回は一業務に集中。二件目として正式価格でご案内します」
- 認証情報・受領禁止情報を渡されそうになったら → 受領前に止める。受領してしまったら即削除+削除した旨を連絡(`09`)
